# FeedWise – Team Contributions

**Project:** FeedWise: Pet and Poultry Supply Sales and Inventory Management System

**Course:** Advanced Web Programming (ITE404)

## Group Members and Responsibilities

| Member | Role | Responsibilities |
|---|---|---|
| Jacquelyn D. Sangalang | Lead Developer | Frontend development using React, TypeScript and Tailwind CSS; backend REST API using Node.js and Express; MongoDB Atlas integration; inventory and sales business logic; dashboard and reporting features; system integration and debugging. |
| Mikaella D. Tarine | Quality Assurance and Documentation | Functional testing of inventory, sales, customers, suppliers and reports; documenting test cases and results; preparing screenshot evidence; reviewing project documentation; assisting with presentation and defense preparation. |

## Development and Testing

### System Development
The system includes product and inventory management, sales processing, automatic stock deduction and restoration, customer and supplier management, dashboard analytics, and sales and inventory reports.

### Quality Assurance
The team will verify the major system features through functional testing, API testing, validation checks, and review of business rules.

## GitHub Contributions

Each member is responsible for committing their own completed work using their individual GitHub account. Commit history will serve as evidence of actual contributions.

## Final Presentation

Both members will prepare to explain the system architecture, database structure, REST API endpoints, frontend functionality, business logic, and testing results.
